# CubeClicker
A browser-based 3D clicker game built with HTML, CSS, JavaScript, Three.js, and Firebase. Click or press Spacebar to make the cube jump, earn clicks, unlock achievements, and rank up. Your highest score is automatically saved using Firebase Firestore.
